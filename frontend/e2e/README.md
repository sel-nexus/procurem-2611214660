# Browser suite

Run from `frontend` with `node node_modules/@playwright/test/cli.js test` after installing frontend dependencies, Playwright Chromium, and the backend requirements. The managed backend uses `$HOME/venvs/procurem/bin/python` by default; set `E2E_PYTHON` to an absolute path to a Python environment containing `backend/requirements.txt` when needed. The configuration starts FastAPI on 127.0.0.1:18100 and Next on 127.0.0.1:13100, waits for both, and routes `/api` through Next to FastAPI. Both ports must be free. It does not reuse running servers.

Each invocation uses a newly named file-backed SQLite database in the guest home directory, seeded by backend startup. `E2E_DATABASE_PATH` is an internal value propagated to workers for the expiry test; do not set it manually. The suite runs with one worker because journeys mutate the shared seed. The temporary database directory remains after the run; remove the `procurem-playwright-*` directory from the guest home directory when no longer needed. Named desktop and mobile screenshots and failure traces are written under Playwright's test-results directory. No application data or external services are required.
